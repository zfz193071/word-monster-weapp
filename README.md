## 安装与检查

使用 Node.js 22 或以上版本，在仓库根目录执行：

```sh
npm ci
npm run check
npm test
```

`check` 检查小程序 TypeScript、工程文件结构和首关内容配置；`test` 使用 Node 测试运行器及 tsx，支持后续不依赖微信运行时的纯逻辑测试。当前测试覆盖导航连点/返回/失败重试、100 个固定随机种子的出题约束、非法配置与资源引用拒绝，不替代微信编译与真机测试。依赖只用于开发，运行时无需构建 npm。

## 微信开发者工具导入

1. 使用有本项目开发权限的微信扫码登录开发者工具。
2. 导入本仓库根目录（不要只选 miniprogram 子目录），确认 AppID 与 project.config.json 一致，项目类型为小程序；无需云开发。
3. 工具读取 miniprogramRoot 和 TypeScript 编译插件，编译到 `pages/home/home`。
4. 点击“开始闯关”创建新会话并进入 `pages/battle/battle`；使用微信左上角原生返回回到首页，再次开始会从第一题创建新局。直接打开缺少有效会话的战斗页会返回首页。
5. 需要自动化验证时，在“设置 → 安全设置”开启服务端口，并在工具提示时授权 Codex 连接。

基础库已固定为开发者工具实际加载的 `3.17.5`（工具版本 `2.02.2609240`）。这是当前模拟器验证版本，不代表已完成真机兼容验收。`project.private.config.json` 是个人配置，不提交；若工具行为与共享配置不符，检查该文件有无覆盖。

真机预览：点击开发者工具“预览”，用有权限的微信扫码，检查两页导航。首次预览涉及微信服务器打包与二维码，请保留工具版本、实际基础库、手机系统、微信版本和结果记录。工程骨架通过不代表整关玩法已验收。

## 内容配置与资源交付

首关词表为 apple、banana、orange、grape、watermelon。`createRounds` 生成初遇/辨词/守关各 5 题，分别使用 1/2/3 个选项；初遇顺序固定，另外两阶段各自洗牌，选项唯一且随机排位。调用时可注入随机源用于复现测试；生成结果被冻结，同题重试不得重新生成。

`Attempt.phase` 显式记录教学/辨词/守关阶段；`hintUsed`、`replayCount`、`attemptIndex` 保留作答条件，避免把教学或提示后完成算作独立答对。异步事件带 sessionId、roundId、revision，供后续引擎丢弃过期回调。

`npm run check:content` 只验证配置，不检查素材已完成。`npm run check:assets` 是词汇资源交付检查：缺文件、未审校、来源或使用权限未确认均返回非零状态。10 项文件现已下载，图片已检查；5 项音频尚待人工听审，因此资源检查仍会报告“尚未审校”，不再报告文件缺失。完整清单见 [docs/content-assets.md](docs/content-assets.md)。

## 关卡引擎

`createSession` 创建内存会话，`reduceGame` 处理带会话/轮次/操作序号的事件并输出新状态和呈现命令。调用方先提交新状态，再执行命令；动画不得自行加能量。引擎已覆盖同题重试、提示记录、升级/护盾、音频错误、暂停恢复和完成幂等。事件、效果、时钟注入及后续适配器责任见 [docs/game-engine.md](docs/game-engine.md)。

首页通过 `sessionStore.start()` 创建并保留唯一会话，战斗页按 URL 中的 sessionId 领取一次；导航失败或退出后释放。会话只存在于内存，无持久化续局入口；后台切换不在首页重新建局。战斗页的 `session` 是后续执行引擎转换的页面内状态，存储器仅负责交接，不负责更新游戏状态。音频接入见 [docs/audio-adapter.md](docs/audio-adapter.md)。

`createBattleController` 连接引擎和音频，页面只提交渲染时的会话/题号/版本及选项 ID。全部图片加载完成且题目发音自然结束后允许选择；选对后呈现攻击并显示单词，等待视觉反馈与揭示发音结束再推进。动画有 900ms 兜底，音频故障由适配器兜底；揭示失败不会撤销已记录的答案。错误反馈后同题重播，第二次错误起保留正确目标高亮。页面隐藏暂停、恢复重新呈现、卸载销毁的基础接线已加入，真机生命周期仍待 #13/#15 专项验收。

#9/#10 已接入包内图音文件，仍待音频听审与模拟器/真机验收。三阶段均已接线：初遇展示图片、英文和发音，辨词/守关作答前隐藏答案文字；每阶段显示题目进度，守关显示引擎结算后的五层护盾。15 题完成后清空答题目标并输出一次完成结果。整关联动测试验证教学、首次独立选择、错后重试、提示后完成可从记录区分，动画不自动作答。
