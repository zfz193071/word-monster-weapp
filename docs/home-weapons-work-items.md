## 已确认

- 首页左右拖动可绕房间水平旋转360°，俯仰角固定。
- 主角扛基础枪，点击主角或枪打开升级面板；中央显示当前枪，按钮显示升级金币价格与金币图标。
- 持续按住每隔1秒升一级，直到松手、金币不足或满级；成功后自动切换展示并装备新枪。
- 武器等级本机持久保存，各局共用；金币扣费和升级必须一致。
- 最新确认：武器等级同时改变外观及普通子弹伤害，数值见本文末；射速与元素技能仍沿用原规则。
- 最新配色顺序为白→蓝→紫→绿→黄→橙黄→红。

## #33 与新需求：等级伤害及命中飘字（已确认并实现）

用户要求不同等级武器造成不同伤害，每次命中显示对应伤害值。此要求替代此前“武器仅改变外观、不改变伤害”的范围；表现使用原创数字动画，不使用其他游戏的美术、音效或界面素材。

确认规则：白→蓝→紫→绿→黄→橙黄→红普通子弹伤害为 1 / 1.5 / 2 / 2.5 / 3 / 3.5 / 4；怪物保持8点生命，元素伤害沿用原数值。数字在受击处上浮淡出，普通与元素伤害分别显示；致命一击显示本次伤害值，不按剩余生命截断。

- 开局将当前已存武器等级纳入本局计划，19波统一继承；战斗角色的枪使用对应等级原创配色，升级面板显示单发伤害。旧计划默认1级。
- 飘字直接取命中伤害事件；普通、火焰、雷电分色且错位，冰霜仅减速不伪造伤害。动画约800毫秒，上浮淡出；清场后最后一击仍完成动画，暂停冻结，销毁清理。
- 169项自动测试及项目检查通过，包含七级子弹伤害、过量伤害、元素分离、19波装备继承、飘字生命周期。
- 微信开发者工具实测从首页听词进入战斗，角色使用红色武器，截图确认“-4”命中及退场飘字；暂停/恢复正常，无场景错误，测试存档已恢复。尚未进行真机验收。
