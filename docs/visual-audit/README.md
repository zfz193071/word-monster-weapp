## 统一规范提案（待审样）

精致卡通、柔和体积感；保持现有绿色守卫、蓝狐、暖色房屋与自然环境的身份。上左方柔光，阴影偏冷且低对比，金属高光小而清楚，毛发以成组明暗表达，水果表皮有细腻质感。实际小尺寸先保证物种和兵种轮廓，不靠密集纹理充数。

战斗保留既有俯视关系、主角背面、防线下方与敌人上方的布局。样张中的角色比例、堡垒造型、装饰密度只是探索，接入以正式绘制坐标和碰撞保持一致为前提。不要照搬概念图生成的UI、敌我数量或建筑高度作为玩法需求。

目视审查发现概念板平板区域给蓝狐画了绿色血条，这是生成偏差：宠物仍免伤、不显示血条，后续正式样张必须去掉。概念板的建筑与单位站位亦不是正式布局；本轮只提交质感方向，不能作为整张战场已符合规格的证据。

透明资源使用真实alpha，不接受棋盘格烘焙背景；分别在浅/深底检查边缘。展示图与战斗部件可独立构图，语义保持一致。中心/脚底/枪口/关节枢轴与原点、素材裁切框写入清单，不能通过改碰撞补偿外观错位。动画优先有限部件和程序动作，禁止未实测就提交高分辨率长序列。

命名采用`{word-or-unit}-{role}-{variant}`，母版只放`docs/`，运行图只保留实际消费尺寸。保留原始来源、生成方式/提示词、许可说明、变更日期和SHA256；旧第三方素材许可不因替换提案而删除。所有新增图先为pending，用户审样后再记录approved。

## 尺寸与预算

当前源码基线：主包1689.3 KiB（剩358.7）、学习分包1109.3 KiB（剩938.7）、图片分包1668.0 KiB（剩380.0）。每包预算2048 KiB。不是微信编译产物。

下载大小与解码内存分开：128² RGBA为64 KiB，256²为256 KiB，512²为1 MiB。27张512²即27 MiB，若同时保留256²变体再加6.75 MiB，尚未计算画布、缓存、纹理副本和其他角色；不能因PNG压缩小便宣称内存低。

试制规格仍按#83：展示256/512，战斗128/256，图标64/128；这些是比较候选，不是已确定预算。先做各档实际DPR 1/2/3、透明边缘、字节和画面比较，再由#86确定分类分包、驻留集合及预算。完整场景含跨关历史类别与Boss标识，不能只预载当前分类。

当前听词图片框高146rpx；战斗普通水果帽图为34×34逻辑单位再乘hatScale，Boss另有放大；主角48×60。检验须读取实际视口scale和DPR，不能把素材原图像素等同显示像素。概念板不满足这一验收。
