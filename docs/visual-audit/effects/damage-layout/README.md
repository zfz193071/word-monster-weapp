# 伤害数字全局避让

2026-11-11，#95/#98。Boss 回放中相邻敌人同时受击时，数字连成一串；原实现只按同一个 monsterId 分配三列，未避让其他敌人的数字，而且22像素列距小于多数伤害文字宽度。

现保留每次实际 `monsterDamaged` 各自的伤害值、颜色、800ms寿命及上浮/淡出。读取正式Canvas的同字体字宽，按最大1.18倍弹出尺寸和描边留空，在附近45个候选位置中选择与当前数字不重叠且距离近的位置。新数字加入后位置固定，后来命中或旧数字到期不会使既有数字换位；屏幕尺寸变化时按新宽度重新排布。上浮速度相同，初次避让的间隔在轨迹中保持。距离搜索有界；极端密度超出可用空间时选择重叠较少的位置，仍不合并、截断或丢弃真实命中。

[四段指定Boss波次回放](motion/review.html)，[逐秒状态及事件](motion/report.json)。沿用上一轮声明的波次/装备配置：铁桶第10波三级武器、王冠第19波五级武器，五级堡垒、普通难度、齐射2/射速2/弹宽1。直接从正式波次工厂开始，未修改敌人位置/血量/伤害/入场；不是从第一波开始的存档通关。视频30fps、DPR1、手机及平板，开场在Boss计划入场前约2秒。此次视频也包含上一轮已修复的王冠预警位置。

项目检查、54项定向回归及539项全量测试通过。四段视频SHA256、ffprobe尺寸与帧数已核对；逐秒状态、事件、Boss阶段、帧数及终局均与上一轮Boss回放一致。手机/平板铁桶分别1210/1368帧，王冠1531/1694帧。新增回归覆盖多个敌人同时受击、三种横向位置、手机/宽屏、整个上浮阶段、后续命中和到期不跳位、暂停重复采样、缩放重新避让、100次同刻命中不丢失。原普通/元素/致命伤害、全宽映射和Canvas回归一并复验。

## 限制

这是数字之间的避让，不是对角色、词条、血条、预警或所有屏幕元素的完整避让；极端密集场景仍可能重叠，数字与原敌人的关联清晰度也需用户审查。未增加屏幕震动或闪烁，未改变伤害及奖励结算。旧特殊兵种造型、预警圆环边缘裁切、整场视觉与设备性能验收仍待完成。本轮不生成位图，不替代真机证据。
