## 实现核查与待完成

当前 `miniprogram/home/room-scene.ts::room` 是两面高墙、床和室内家具的剖面；`hero`、`fox` 与房屋通过同一三维投影、遮挡排序及可见面命中测试绘制。不能把这张单视角图片直接盖到首页，冒充保留了360°旋转和遮挡点击。

后续正式实现需：

- 用完整房屋外景和独立外围堡垒替代室内剖面；保留角色、宠物活动空间及可见点击区域。
- 五级房屋/堡垒有对应升级表现；沿用已确认价格与属性，不由概念细节推导新规则。
- 主角七级枪械、宠物实际拥有状态与成长外观继续读正式存档，未拥有宠物时不固定画出蓝狐。
- 将房屋、外围墙、主角及宠物的投影、遮挡、阴影、命中测试统一；校验旋转四方向、完整360°、弹层遮挡与关闭恢复、后台及尺寸变化。
- 同步模型边界与视口缩放，避免屋顶、角塔和烟雾裁切；保留首页已有功能入口。
- 手机/iPad实际比例与高DPR画质、包体、动态性能和真机验收；静态样张不能当作运行时完成。

本轮只完成明确需求记录、旧范围承接和完整美术样张，未修改运行时首页。
