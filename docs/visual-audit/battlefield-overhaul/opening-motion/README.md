# 首轮自然进攻离屏回放

入口：[手机与平板回放](review.html)。使用正式 `createOpeningEncounter` 和 `CanvasScene`，第一关普通难度、一级武器和堡垒，无技能、无宠物；两端共用同一种子。未改血量、位置、刷怪、射击或伤害规则，不访问玩家存档。

30fps、1倍速、DPR 2；确定性时钟推进首轮，清场/失败后保留1秒，最多40秒。视频使用原始RGBA送入ffmpeg编码，PNG关键帧保留原始DPR 2。`report.json`记录实际帧数、最终状态、逐秒位置、事件计数、资源及视频SHA256；断言8只计划怪物实际入场、有真实伤害、无丢弃模拟时间，且销毁后的迟到帧不恢复场景。

复现（依赖已有离屏工具及本机ffmpeg，不加入小程序依赖）：

```sh
WM_CANVAS_MODULE=/path/to/@napi-rs/canvas node --import tsx scripts/render-opening-motion.mts
```

可通过 `WM_OPENING_OUTPUT` 输出到其他目录，避免覆盖已审证据。
