# #85 动物学习展示图

2026-11-09开始制作。沿用已采用的精致卡通画风，复用兔子、蓝鸟展示样张；其余14种逐张使用内置 image_gen 生成，以兔子为风格参考。准确提示词见 [prompts.json](prompts.json)，复用样张提示词见 `../samples/prompts.json`。

本轮结果：14/16种可审查，缺马、狮子，两者首次及原提示词重试均被图片服务以`moderation_blocked`（输出阶段、`other`）拒绝；狗首次同类失败、原提示词重试成功。未切换CLI或其他服务。原始错误和请求ID见生成记录。

鸭子首图带宽幅灰白背景，鱼首图误带哺乳动物鼻口；已用内置图片编辑分别修正，采用`duck-clean.png`与`fish-corrected.png`。原始失败图保留作问题证据，不进入候选；编辑提示词见`refinement-prompts.json`和`fish-refinement-prompt.json`。

14张采用母版通过真实透明与画布边缘检查，56个尺寸候选生成；70份母版/候选的字节及SHA256复核通过。128档合计265.7KiB、256档891.6KiB、512档3057.8KiB，仅统计现有14词；512档超过单包源码预算，不能直接整套接入。后台Chrome审样页84个图片引用全部解码成功，1440视口无横向溢出。

已目视核对母版及浅深底24/48/96尺寸总览：灰猫/橙色条纹虎、棕熊/黑白熊猫、红冠尖喙鸡/黄鸭扁喙有可见差别，长鼻/耳/尾保留；24像素细纹理明显弱化。蜜蜂面部偏拟人，最终风格审查仍须关注，未视为用户已批准。没有微信模拟器、自然动态或真机证据。

## 重建与检查

```sh
WM_CANVAS_MODULE=/tmp/wm-render-tools/node_modules/@napi-rs/canvas node --import tsx scripts/prepare-animal-art.mts
```

`WM_CANVAS_MODULE`指向本机可用的`@napi-rs/canvas`；该离屏工具不是游戏运行依赖。默认严格检查16种动物的母版齐全；`--allow-incomplete`仅用于明确显示缺项的进度页。

脚本直接读取正式第三关词表，检查提示词覆盖及学习音频文件存在，检查真实透明alpha和主体没有触碰图片边缘。等比例生成64/128/256/512候选，保留透明通道，无损PNG编码，不量化或抠图；尺寸候选不全部装入运行包。下载字节与RGBA解码估算分别记录，实际微信包体、内存及清晰度须另测。
