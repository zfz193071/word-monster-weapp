```sh
WM_CANVAS_MODULE=/tmp/wm-render-tools/node_modules/@napi-rs/canvas node --import tsx scripts/prepare-animal-art.mts
```

`WM_CANVAS_MODULE`指向本机可用的`@napi-rs/canvas`；该离屏工具不是游戏运行依赖。默认严格检查16种动物的母版齐全；`--allow-incomplete`仅用于明确显示缺项的进度页。
