## 产物与使用边界

- `originals/`：六张生成母版，保留原始PNG与alpha，不进入运行包。
- `variants/`：展示256/512，战斗64/128/256候选；只做高质量缩小与PNG无损编码，未量化颜色、未手动抠底。64档用于比较最小图标/小尺寸极限，不代表最终统一规格。
- `manifest.json`：尺寸、字节、SHA256、透明/半透明像素计数和内容边界；RGBA为宽×高×4，非实测驻留内存。
- [review.html](review.html)：原图浅深背景、尺寸/字节对照、可切换手机/平板比例与DPR的检测条、完整静态场景。
- `scenes/`：当前正式CanvasScene离屏绘制，固定6/18只怪的审样夹具，替换苹果词标与兔/鸟外观；不修改游戏代码、碰撞、数值、生成规则或存档。不是真机截图或自然混战。

苹果作为普通僵尸的独立学习帽标，不新增拟人水果敌人。兔/鸟保留物种特征与轻度卡通僵尸化。蓝鸟翅膀姿态不意味着实现飞行兵种或空地承伤。宠物沿用当前免伤表现，不显示血条。

## 尺寸口径

正式代码中苹果普通帽标34×34再乘40/64，实际21.25逻辑像素；全宽视口scale=高度/560，手机390×620下约23.53 CSS像素、平板1024×580下约22.01 CSS像素。DPR3对应约70.6/66.0物理像素，战斗128档足以覆盖这一普通帽标尺寸，但不由此判定Boss放大图也足够。

动物本轮在48逻辑像素方框中合成，保留母版透明留白；这是候选外观框，未修改现有动物碰撞。实际可见主体小于方框，耳尖/翼尖与脚底锚点仍待接入时校验。未拆分关节部件，也没有动画交付。

展示图候选256/512须结合146rpx听词图片框及设备DPR判断；原图细节与压缩率不能单独作为验收。预算不能把母版和全部候选同时计入计划运行包。
