## 本轮动作

新增 `bossPose`，只读取正式 tick、spawnAtMs 与既有冲锋/蓄力阶段。预备时轻微压低身体，冲锋/冲击波释放时身体随动；脚部锚点、腿部距离步态不变。铁桶接敌后交回原有攻击动作，等待或死亡不播放蓄力。没有新增攻击、计时器或伤害事件。

项目检查及535项全量测试通过。新增集成回归从正式波次逐步推进，验证王冠身体释放出现在真实冲击波的首个10ms模拟步，并验证铁桶预警、冲锋、接敌姿势。入场时间可能不是10ms整数倍，测试按一个模拟步的上限核对，未修改原战斗时间。
