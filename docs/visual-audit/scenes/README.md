## 逐关处理结论

以下为审查建议，不是已替换或用户最终验收。八关保留全宽地面、原配色身份及边缘装饰位置；后续优化共用地砖的描边和材质层次，先以第一关完整场景审样，再复核其余配色，避免八关各自成为不同画风。

| 关卡 | 保留 | 优化重点 |
| --- | --- | --- |
| 1 水果 | 黄绿庭院、果树边饰 | 地砖缝线规律明显，弱化重复感；果帽维持视觉重点 |
| 2 颜色 | 淡紫底、彩色花 | 保留与绿皮肤的分离度，地砖明暗不压过词帽 |
| 3 动物 | 绿灰树林、树木边饰 | 绿底与绿皮肤接近；后续需追加真实动物形态的对照 |
| 4 学习工具 | 浅灰黄庭院、书本边饰 | 细化书本层次，但不扩展到进攻区 |
| 5 家居物品 | 暖棕露台、窗格边饰 | 与木堡垒同属暖色，保持地面/防线边界 |
| 6 日常物品 | 暖桃广场、礼盒边饰 | 与第5关色调近，保留礼盒区别，不能仅靠换色认关 |
| 7 自然现象 | 蓝灰湖畔、水纹边饰 | 保留冷暖分离，水纹不增加高亮运动噪声 |
| 8 身体部位 | 灰绿庭院、哑铃边饰 | 保留低饱和底色；边缘小装饰不承担学习内容 |

## 五级房屋处理结论

| 等级 | 保留结构 | 后续协调 |
| --- | --- | --- |
| 1 木屋 | 首页木墙与战斗木墙 | 木纹/柔光统一，不改防线区域 |
| 2 加固木屋 | 加固立梁、横梁和铆钉 | 保留升级区别，协调梁材质 |

当前战斗房屋函数在480～560逻辑防线区裁剪，升级结构已实现；不重做或改变等级属性。首页为多面体造型，战斗为描边/色块造型，与新精致素材仍有材质差异。受击闪光和摧毁废墟沿用既有逻辑，本轮固定完整堡垒图不能证明这些状态一致。
