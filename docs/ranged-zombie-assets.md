# 远程僵尸美术资源需求

## 概述

工单 #111 新增两种远程攻击僵尸类型：弓箭僵尸和投石僵尸。本文档列出所需美术资源。

## 1. 弓箭僵尸 (Archer Zombie)

### 属性
- 射程：200px
- 伤害：基础伤害的 15%
- 射速：2 秒/发
- 血量：同级别近战僵尸的 70%
- 出现率：后期波次 5%-8%

### 所需资源

#### 造型图 (Portrait)
- 文件名：`zombie-archer-portrait.svg/png`
- 尺寸：建议 128x128px
- 说明：正面半身像，手持弓箭，需体现远程特征

#### 动作精灵图 (Sprite)
- 文件名：`zombie-archer-sprite.svg/png`
- 尺寸：建议 64x64px 每帧
- 帧数：
  - 行走动画：4-6 帧
  - 拉弓前摇：2-3 帧
  - 射击动作：2-3 帧
  - 受击动画：2 帧
  - 死亡动画：3-4 帧

#### 攻击特效
- 箭矢飞行轨迹：`arrow-projectile.svg`
- 箭矢命中效果：`arrow-hit-effect.svg`
- 尺寸：箭矢约 16x8px，命中特效约 32x32px

#### 碰撞框参考
```typescript
{ x: -16, y: -32, width: 32, height: 64 }
```

## 2. 投石僵尸 (Stone Zombie)

### 属性

- 伤害：基础伤害的 25%
- 射速：3.5 秒/发
- 血量：同级别近战僵尸的 60%
- 出现率：后期波次 5%-7%

### 所需资源

#### 造型图 (Portrait)
- 文件名：`zombie-stone-portrait.svg/png`
- 尺寸：建议 128x128px
- 说明：正面半身像，手持石块或投石器，体型可略大于弓箭僵尸

#### 动作精灵图 (Sprite)
- 文件名：`zombie-stone-sprite.svg/png`
- 尺寸：建议 72x72px 每帧
- 帧数：
  - 行走动画：4-6 帧
  - 蓄力前摇：3-4 帧
  - 投掷动作：2-3 帧
  - 受击动画：2 帧
  - 死亡动画：3-4 帧

#### 攻击特效
- 石块抛物线轨迹：`stone-projectile.svg`
- 石块命中效果：`stone-hit-effect.svg`
- 尺寸：石块约 12x12px，命中特效约 40x40px

#### 碰撞框参考
```typescript
{ x: -18, y: -36, width: 36, height: 72 }
```

## 3. 视觉区分要求

### 与近战僵尸的区别
1. **手持武器**：弓箭/投石器必须明显可见
2. **姿势**：远程僵尸站立姿势略高，体现准备攻击状态
3. **颜色标识**：建议使用不同配色区分远程类型
   - 弓箭僵尸：绿色/棕色系
   - 投石僵尸：灰色/土黄色系

### 弹道区分
1. **箭矢**：直线飞行，带尾迹
2. **石块**：抛物线轨迹，落地有撞击效果
