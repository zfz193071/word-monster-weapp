# 波间技能（#11）

实现依据：已确认的 A1—C8，特别是前四波随机二选一、每种最多三级、仅本局有效。

## 会话接口

`createSkillSession(plan, random)` 为每局建立独立的技能账本。`levels` 与 `offers` 均为不可变快照，后者保留每波候选与已选结果。

- 波次编排器在退场读词完成后调用 `open(clearedCombat)`。只有本局已清除的前四波、基地存活、前一波已领取且技能等级匹配时才生成候选。同波再次调用返回已有记录，不消耗随机数。
- `select(offerId, skillId)` 仅消费当前未选 offer，返回已选状态；旧 ID、重复点击、非候选、暂停或销毁后的操作返回 null。每次领取只增加对应等级一次。
- `setPaused(true)` 禁止抽取和领取，恢复保留原候选。退出/重玩时 `dispose()`，新局创建新实例，不跨局恢复技能。
- 下一波将 `levels` 原样传给 `createCombat`，由既有模拟器计算弹数、射击间隔和弹宽。技能模块不开始下一波，不写学习或永久奖励记录。
- 编排器仍负责验证退场回调的完整上下文，并在失败/结束时销毁会话；不能用技能领取跳过下一波听词判断。

## 当前页面验证入口

开发版 `pages/battle/battle?preview=fortress`：开始战斗 → 击败并完成退场 → 显示两个技能按钮 → 领取后显示升级数值。面板位于 Canvas 外，避免原生层遮挡。暂停期间按钮不可领取，重新预览或切换水果会清空。

此入口只验证一波的技能交互。正式五波接线、升级后连续战斗的画面及真机性能由 #10/#15 联合验收，当前不把开发预览当作完整游戏。

## 验证

`tests/skills.test.ts` 验证单次抽取、暂停、重复/旧卡片、非候选拒绝、异局/战斗中/失败/最后一波不出奖励、重开清零、固定种子重放，以及三种技能的三级封顶。效果通过真实 `createCombat` 和 `stepCombat` 检查弹体数量、宽度、下一轮发射时刻，不只断言 UI 文案。
